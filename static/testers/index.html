Fayda Onboard

Pilot tester build — Android APK against the live sandbox stack.

1. Install the Android app

Enable “Install unknown apps” for your browser/files app, then install the APK.

Download APK

2. Point the app at this API

Open the gear icon in the app and set Base URL to:

https://YOUR-SERVICE.onrender.com

Cold starts on the free tier can take ~30–60s after idle. Wait for the first request.

3. Test flow

  1. Select Awash Bank → Agree to consent
  2. Enter any 12-digit FIN (example 123456789012)
  3. OTP is always 123456 in the Fayda sandbox
  4. Capture a live selfie → fill bank fields → sign → submit
  5. Wait for account number → Activate
