# Fayda Onboard brand assets

High-quality exports for reuse (marketing, stores, decks). The live Flutter app still draws the welcome card in code and loads the icon from `mobile/assets/icon/app_icon.png`.

| File | Use |
|------|-----|
| `fayda-onboard-app-icon.png` | Master app icon **1024×1024** (same as shipped Android) |
| `fayda-onboard-app-icon-2048.png` | Upscaled **2048×2048** for print / large placements |
| `fayda-onboard-welcome-hero.png` | Tall onboarding card with title + copy |
| `fayda-onboard-welcome-hero-bg.png` | Same card background **without text** (drop your own copy on top) |
| `fayda-onboard-banner-1920x1080.png` | Wide marketing banner |
| `fayda-onboard-welcome-hero-ai-alt.jpg` | Alternate AI-styled hero (optional) |

Palette: navy `#0A2540`, teal `#0F766E`, gold `#B8923A`.
